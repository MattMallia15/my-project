# Investment Strategy

## Style
Value investor. My edge is identifying companies whose intrinsic value the market has mispriced — usually to the upside, but I'll fade overvaluation when it's egregious. Concentrated single-name book wrapped in multi-asset diversification.

## Screening framework

**Quantitative gate** — a name must come up cheap on at least one of these to be on the radar:
- P/E (absolute and vs. sector / its own history)
- P/B
- P/S
- EV/EBITDA
- PEG (growth-adjusted)

**Quality / safety overlay** — to filter cheap-for-a-reason value traps:
- Debt-to-equity
- Free cash flow (level + trend)
- Revenue growth (TTM and trend)
- Net income growth
- Dividend yield + payout ratio (sustainability)
- Beta
- Altman Z-score (bankruptcy risk)

## Process after the screen
1. **Understand WHY it's cheap.** Real problem (broken thesis, structural decline, regulatory) or temporary (cycle, one-off, sentiment, broad de-rate)? I only invest if the market is wrong about the *why*.
2. **Cross-check with sell-side.** Am I alone or is consensus arriving? Either is fine, but I need to know which.
3. **Macro overlay.** Rates, FX, commodities, geopolitics. Does the trade work in the regime I think we're in?
4. **Sizing depends on conviction + macro fit + how cheap, not on screen rank alone.**

## Time horizon
Months to 1-2 years per position. I am not a forever holder. I exit when the gap to fair value closes or when the thesis breaks.

## Asset allocation
Diversification across asset classes is non-negotiable:
- **Single-name equities** — the alpha engine
- **Broad / regional ETFs** — beta + geographic diversification
- **Commodities** (gold, silver) — macro hedge / store of value
- **Bonds** (treasury ETFs) — duration + cash-like

Multi-currency, multi-region equity exposure (US, Europe, Asia, ANZ) is deliberate.

## Sell rules
I sell when ANY of:
1. Price reaches my fair-value estimate.
2. The original thesis is invalidated by fundamentals — not by price action alone.
3. A materially better opportunity needs the capital.
4. Position has drifted past size cap and trimming is healthy.

I do NOT sell because:
- A single bad headline that doesn't change the thesis.
- Price went down but fundamentals are intact.

## Hard rules
- **No options, no leverage, no shorting** unless this file is updated. Existing CFDs in the eToro account are treated as cash-equivalent long exposure, not as leverage to expand.
- **No crypto** unless this file says otherwise.
- **Tactical positions** (e.g., AI hype riders) must be explicitly tagged `tactical` in the journal so they aren't confused with value holdings.

## What the portfolio-manager agent should do for me
- **Devil's advocate by default.** When I'm bullish, build the bear case. When I'm bearish, build the bull case. Both sides, every time. Not optional.
- **Question approaches.** If a proposed trade contradicts this file or contradicts my current `market_view.md`, name it before discussing merits.
- **Find candidates** that pass my screen: cheap on valuation, clean on quality (low debt, positive FCF, no Altman red flags), with a macro tailwind.
- **Side-by-side comparisons** when I'm choosing between names.
- **News surveillance** on every holding and every open-order ticker. Classify as thesis-affecting / sentiment / noise.
- **Earnings calendar** for every holding, with the date, time (ET), and what the print needs to show.
- **Macro calendar** — releases relevant to current positioning (CPI, PCE, FOMC, NFP, ISM, retail sales, oil inventories given my energy exposure).
